# Shell, init files, variables and expansions

- 0-alias: Creates the ls alias.
- 1-hello_you: Prints hello and the current user.
- 2-path: Adds /action to PATH.
- 3-paths: Counts the entries in PATH.
- 4-global_variables: Displays environment variables.
- 5-local_variables: Displays shell variables and functions.
- 6-create_local_variable: Creates BEST with value School.
- 7-create_global_variable: Exports BEST with value School.
- 8-true_knowledge: Adds 128 to TRUEKNOWLEDGE.
- 9-divide_and_rule: Divides POWER by DIVIDE.
- 10-love_exponent_breath: Raises BREATH to the power LOVE.
- 11-binary_to_decimal: Converts BINARY from base 2 to decimal.
- 12-combinations: Prints letter combinations except oo.
- 13-print_float: Prints NUM to two decimal places.
- 14-decimal_to_hexadecimal: Converts DECIMAL to hexadecimal.
